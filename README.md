## About

This presentation showcases six specialized AI agents that automate repetitive engineering tasks:

- **pr-stacker** - Split large PRs into reviewable stacks
- **pr-comment-reviewer** - Systematically triage PR comments
- **analyze-queue** - Identify and fill in incomplete sprint tickets
- **ticket-scoper** - Collaborative ticket breakdown
- **commit-message-writer** - Generate conventional commits
- **doctor-mobile-release-notes** - Automated release documentation
